- 验证：`import webapp` 成功，`app.title = 世方·智枢文档`。
- 已把版本兼容要求写入 MEMORY.md。

## 诊断预览 400：`GET /jobs/cf7008a8d2f9414ba295cc3e79393b22/preview/output`
- 根因：跨环境数据不一致，非代码 bug。数据库是远程共享 MySQL（192.168.2.60:3306），Linux 服务器与本地 Windows 共用。该 job 在 Linux 服务器（`/data/gitlab/smartmd`）跑成功，DB 里 output_file/output_root 存的是 Linux 绝对路径 `/data/gitlab/smartmd/data/output/cf7008.../`，本地 Windows 磁盘无此目录，本地 fallback `data\output\{job_id}\` 也不存在 → 预览代码 `_job_output_dir` 三个候选目录全找不到 → 400「未找到转换结果目录」。
- 代码逻辑（src/web/webapp_preview.py）：不带 path 参数时，按 output_file → output_root → workspace_output_root/job_id 顺序找目录，再 rglob *.md。有 workspace fallback，只要本地 `data\output\{job_id}\` 存在且有 md 文件即可预览，即便 DB 里是别环境的绝对路径。
- 本地 data/output 有 22 个 job 目录（本地跑的，路径正常），cf7008 不在其中。
- 方案：①去服务器预览 ②把服务器输出目录拷到本地 data\output\{job_id}\ ③根治：output 路径改相对存储（待用户确认是否做）。
